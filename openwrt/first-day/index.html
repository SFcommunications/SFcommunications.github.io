RouterOS

  1. RouterOS must be configured to install OpenWRT via netboot. Grab the proper version’s files here

  2. We are using Version 6.49.10, extract all files from the .zip you downloaded from the above step.

  3. Log into the RouterOS gateway https://192.168.88.1 and go to FILE and upload everything from the netboot zip file.

  4. Go to SYSTEM>PACKAGE and click on DOWNGRADE to downgrade the OS.

  5. Backup your RouterOS License Key by going to SYSTEM>LICENSE>EXPORT KEY

  6. Prepare the device for netboot by going to SYSTEM>ROUTERBOARD>SETTINGS and configuring the following.

  1. Power off the Router until ready to netboot.
