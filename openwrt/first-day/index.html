RB750Gr3

  1. RouterOS must be configured to install OpenWRT via netboot. Grab the proper version’s files here

  2. We are using Version 6.49.10, extract all files from the .zip you downloaded from the above step.

  3. Log into the RouterOS gateway https://192.168.88.1 and go to FILE and upload everything from the netboot zip file.

  4. Go to SYSTEM>PACKAGE and click on DOWNGRADE to downgrade the OS.

  5. Backup your RouterOS License Key by going to SYSTEM>LICENSE>EXPORT KEY

  6. Prepare the device for netboot by going to SYSTEM>ROUTERBOARD>SETTINGS and configuring the following.

  1. Power off the Router until ready to netboot.

In the last step we downgraded RouterOS to a version that will accept OpenWRT netbooting.

Now we prepare our computer/workstation to be the server that Net installs the router with OpenWRT.

  1. Download the proper image version for netbooting.

  2. Download the sysupgrade image to finish the installation.

  3. Create a directory on your home Directory called tftp and go to that Directory.

cd ~
mkdir tftp
cd /tftp
  1. create a .sh file named “loader”
nano loader.sh
  1. copy and paste the following into loader.sh, ensure USER= the user home directory and IFNAME= the name of your ethernet interface.
#!/bin/bash
USER="name"
IFNAME="enp0***"
/sbin/ip addr replace 192.168.1.10/24 dev $IFNAME
/sbin/ip link set dev $IFNAME up
/usr/sbin/dnsmasq --user=$USER \
--no-daemon \
--listen-address 192.168.1.10 \
--bind-interfaces \
-p0 \
--dhcp-authoritative \
--dhcp-range=192.168.1.100,192.168.1.200 \
--bootp-dynamic \
--dhcp-boot=openwrt-23.05.0-rc3-ramips-mt7621-mikrotik_routerboard-750gr3-initramfs-kernel.bin \
--log-dhcp \
--enable-tftp \
--tftp-root=$(pwd)

  1. IMPORTANT: ensure the initramfs-kernel.bin file is located in the tftp directory. this script is counting on it being there.

  2. Make the script executable:

chmod +x loader.sh
  1. We can run the script when ready to turn on the server.
./loader.sh

  1. Navigate to /tftp and run loader.sh

  2. Connect your computer/workstation/TFTP server to the WAN port of the router with an ethernet cable.

  3. Hold reset button when powering on, do not let go until the router beeps once, you should also see activity in the terminal window.

  4. Shut down loader.sh with ctrl+c.

  5. Disconnect Ethernet from WAN and connect to port 2,3,4, or 5.

  6. Confirm OpenWRT installed sucessfully by navigating to the gateway at https://192.168.1.1

  7. Do not create a password yet, OpenWRT is currently running in memory, we need to upgrade the firmware with the sysupgrade image we downloaded earlier. Click on SYSTEM>BACKUP/FLASH FIRMWARE.

  8. Click Flash New Firmware Image and upload the syspugrade file from earlier steps.

  9. Continue

  10. Wait for a few moments for the system to upgrade, OpenWRT will now be flashed to storage and you can restart the router to make sure it boots OpenWRT normally.

  11. log into https://192.168.1.1 and change your password.
