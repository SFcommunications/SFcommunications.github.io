EAP225 V3 or V4

https://forum.openwrt.org/t/anyone-working-on-tp-link-eap225/33956

  1. Like the EAP615, The EAP225 (v3 or v4) is rather easy to flash openWRT to. In this case, there is only one Ethernet port on the EAP225.

  2. Use your router to find out what IP address is being used by the EAP225. Login to the WEBUI with admin/admin. Ignore the following error, go to advanced and PROCEED.

You may have to complete TPlinks initial setup to access the GUI.

Enable SSH in the MANAGMENT tab.

  1. Next we need to do to the device is turn off certificate verification using SSH. open a terminal and SSH into the EAP225

Change the IP address in the command below to the EAP225 IP address.

ssh -oPubkeyAcceptedAlgorithms=+ssh-rsa -o HostKeyAlgorithms=ssh-rsa -oKexAlgorithms=+diffie-hellman-group1-sha1 admin@192.168.0.254

Then stop the cert verification daemon

cliclientd stopcs

Full OpenWRT Documentation for EAP225

  1. Rename the OpenWrt …squashfs-factory.bin binary to factory.bin (The GUI has a limit on the file name length, shortening to e.g. factory.bin works.)

  2. Upload the firmware on the firmware update page on the TP-link web GUI.

WARNING Failing to use the correct image for your device may cause it to brick. We used this factory image for our V3 outdoor model.

  1. Reconfigure your static IP to talk to OpenWrt on 192.168.1.1 (the OpenWrt default).

  2. Connect your workstation to a POE switch or connect your workstation directly to the EAP225

  3. Go to NETWORK then INTERFACES and select the ETH0 or (br-lan) interface and add another IPv4 address that is not being used on your current network. Set Gateway and subnet information.

Go to ADVANCED SETTINGS and add at least on DNS server, we added 3.

SAVE AND APPLY the changes, and reboot the router.
