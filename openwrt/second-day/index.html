OpenWRT Install

In the last step we downgraded RouterOS to a version that will accept OpenWRT netbooting.

Now we prepare our computer/workstation to be the server that Net installs the router with OpenWRT.

  1. Download the proper image version for netbooting.

  2. Download the sysupgrade image to finish the installation.

  3. Create a directory on your home Directory called tftp and go to that Directory.

cd ~
mkdir tftp
cd /tftp
  1. create a .sh file named “loader”
nano loader.sh
  1. copy and paste the following into loader.sh, ensure USER= the user home directory and IFNAME= the name of your ethernet interface.
#!/bin/bash
USER="name"
IFNAME="enp0***"
/sbin/ip addr replace 192.168.1.10/24 dev $IFNAME
/sbin/ip link set dev $IFNAME up
/usr/sbin/dnsmasq --user=$USER \
--no-daemon \
--listen-address 192.168.1.10 \
--bind-interfaces \
-p0 \
--dhcp-authoritative \
--dhcp-range=192.168.1.100,192.168.1.200 \
--bootp-dynamic \
--dhcp-boot=openwrt-23.05.0-rc3-ramips-mt7621-mikrotik_routerboard-750gr3-initramfs-kernel.bin \
--log-dhcp \
--enable-tftp \
--tftp-root=$(pwd)

  1. IMPORTANT: ensure the initramfs-kernel.bin file is located in the tftp directory. this script is counting on it being there.

  2. Make the script executable:

chmod +x loader.sh
  1. We can run the script when ready to turn on the server.
./loader.sh
